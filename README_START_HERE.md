# ☕ Kiln Coffee House - START HERE

## 🚀 See Your Website in 2 Steps!

---

## Step 1: Start MongoDB

Open **Command Prompt** or **PowerShell**:

```bash
docker run --name kiln-mongo -p 27017:27017 -d mongo:latest
```

*Don't have Docker? See [HOW_TO_VIEW_WEBSITE.md](HOW_TO_VIEW_WEBSITE.md) for other options.*

---

## Step 2: Launch Website

**Just double-click:** `START_WEBSITE.bat`

---

## ✨ That's It!

Your browser will automatically open to:

## 🌐 **http://localhost:1995**

---

## 🎯 What You'll See

Your full coffee shop website with:

- ☕ **Menu** - Browse coffees, bakes, and plates
- 🛒 **Orders** - Place orders online
- 📅 **Bookings** - Reserve tables
- 👤 **User Accounts** - Register & login
- 🔧 **Admin Panel** - Manage everything
